# FancyTileEntities

FancyTileEntities port for the Shared runtime. Workspace location: `Mods/FancyTileEntities/`.

Projects:

- `Celeste.Mods.FancyTileEntities.csproj`

Repository dependencies: **Shared**. Prepare Shared resources using the [Tools README][tools-readme], then build the main project:

```powershell
dotnet build ./Mods/FancyTileEntities/Celeste.Mods.FancyTileEntities.csproj -c Release
```
